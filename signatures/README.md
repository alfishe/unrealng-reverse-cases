# The signature base

Known pieces of ZX Spectrum programs: AY players, packers, protections, loaders, system routines, fonts, ROM calls,
and the modules of the finished cases. A scan of a new image names the known pieces with their base address and
annotations for the case's `.ann`.

The format, the folder tree and the match rules: [docs/signature-format.md](../docs/signature-format.md).

| Path | What |
| --- | --- |
| `<domain>/<family>/<name>/<variant>/` | one entry: `sig.json`, `code.bin` or `data.bin`, `detect.py` for formats, `notes.md` |
| `index.json` | the search index, generated by `kit/sig_index.py`, never edited by hand |
| `INDEX.md` | every entry by folder, generated |

The domains: `sound/`, `packers/`, `protection/`, `disk/`, `tape/`, `system/`, `graphics/`, `rom/`, `programs/`
(the cases' own modules), `formats/` (data formats found by structure).

Adding an entry and checking the base (the two scripts are the next step; the format is their specification):

```bash
python3 kit/sig_index.py --check     # ids, hashes, masks, kinds, roles, variant links
python3 kit/sig_index.py             # writes index.json and INDEX.md
python3 kit/sig_scan.py IMAGE --base ADDR [--ann]
```
