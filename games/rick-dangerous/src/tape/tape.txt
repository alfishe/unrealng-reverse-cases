#   tzx MAJOR.MINOR                         the file header ("ZXTape!", $1A, the version)
#   text TEXT                               a text description block ($30)
#   header PAUSE TYPE NAME LENGTH P1 P2     a standard ($10) ROM header: flag $00, type 0 (Program) or 3 (Bytes), the
#                                           name padded to 10, the length ("@FILE": the file's), P1, P2 ("=": the length)
#   data PAUSE FILE                         a standard ($10) data block: flag $FF, the file, the XOR checksum
#   group TEXT / group-end                  a group start ($21) and end ($22)
#   tone PULSE COUNT                        a pure tone ($12): COUNT pulses of PULSE T-states
#   pause MS                                a pause ($20)
#   turbo PILOT SYNC1 SYNC2 ZERO ONE LAST   the timings of every turbo ($11) block after it
#   key KEYPAGE RICK1                       group 1's key: the tape's key page XOR Rick1's two pages
#   g1 PILOTS PAUSE NUM DEST ITEM FILL JP   a group 1 block: PILOTS pilot pulses, the pause after it in ms, its number,
#                                           where it goes, the 256 plain bytes (enciphered by the key in $CF00-$FBFF
#                                           and in $5D40-$5DFF), the filler (hex: as long as the previous block's
#                                           checksum asks) and the JP after it
#   g23 GROUP PILOTS PAUSE NUM DEST END GO ITEM   a group 2 or 3 block: ITEM's 256 bytes, each XOR DEST's high byte;
#                                           END the high byte after the group's last page, GO where to go after it
# ITEM is a file of build/ (or build/res/) or FILE@ORG:ADDR, the 256 bytes at ADDR of FILE, whose first byte is at
