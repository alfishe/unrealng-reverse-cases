## Terms

Each term once, here; the documents use these names and no others.

| Term | Meaning |
| --- | --- |
| AY player | the music and effects engine copied to RAM 1 at `$C000`; AyTick `$C46C` runs once a frame from the interrupt (through SoundTick `$A030`) on the 128K (doc 9) |
| beeper effect | the 48K sound path: BeeperEffect `$A08E`, a blocking loop on port `$FE` instead of the AY player (doc 9) |
| cell flags | CellFlags `$6C00`: one byte per char cell of the map window (`$6C00` + 32 x row + column); non-zero: DrawDirtyCells redraws the cell; `$6F00` ends the scan (doc 6) |
| channel record | 18 bytes per AY channel (ChannelA `$C0AB`, ChannelB `$C0BD`, ChannelC `$C0CF`): the masks, the period, the volume, the envelope phase (doc 9) |
| char map | `$6500-$6A7F`: one char code per cell, 32 columns x 44 rows; rows 8-31 (`$6600-$68FF`) are the screen (doc 6) |
| char properties | `$5C00-$5CFF`: one byte per char code (ladder, deadly, in front, platform, spring, wall, floor), built by BuildCharProps `$F6A9` from CharPropsSet0 or CharPropsSet1; the resource `src/res/levels/charprops.txt` (doc 6, 10) |
| composed char | a char built at `$5CF0` + 8n where a sprite overlaps the scenery: the background char with the sprite masked in; its number replaces the char in the char map (doc 6) |
| EffectChannel | `$C6E4`: the channel of the last effect; AyPlayEffect `$C685` puts each new effect on the next channel, the first on B (doc 9) |
| exit | 5 bytes of a zone's exit list (side, row, zone, row there); `$FFFF` as the zone ends the level (doc 7) |
| HUD | the row of the score, the lives, the bullets (Bullets `$A976`) and the dynamite (Dynamite `$A967`), each count drawn as its icons (doc 8) |
| kind | an object's type byte in its slot: 1 Rick, 2 bullet, 3 dynamite, 4-15 enemies, 16-17 boxes, 18-21 treasures, 22-23 the timed bonus, 24 and up traps (doc 7) |
| LevelBonus | `$A9E3`: (lives + 1) x 10 000, paid at the end of level 4 only (doc 10) |
| LevelTable | `$E4AE`: 5 records of 11 bytes (the intro text, its place, char 0's attribute at `$7900`, Rick's start, the first zone, LevelViewTop: the first view row); the fifth is the ending; the resource `src/res/levels/leveltable.txt` (doc 2, 7) |
| map char row | a row of 8 pixels in a zone's map, one char high; a tile row is 4 of them (doc 1, 6) |
| object table | ObjectTable `$EA8E`: 12 slots of 30 bytes; slot 1 is Rick, 2 his bullet, 3 his dynamite (doc 7) |
| pass | one run of MainLoop `$E3C9`: 2 frames in play (a HALT at `$E40F`, then WaitFrames), 3 when an interrupt is lost (doc 4) |
| spawner | SpawnObjects `$FD7D`: starts the objects of a zone's list (Objects `$D7FC`) in the rows coming into the view (doc 7) |
| tile | 4 x 4 char codes, 16 bytes at Tiles `$C31C` + 16 x tile; BuildScreenMap `$AD5A` fills the char map with them (doc 6) |
| timed bonus | kinds 22 and 23: touching the first starts 2 000 counting down by 10 every 30 passes, reaching the second pays what is left (doc 10) |
| zone | one tall map with its exits and objects, a 7-byte record at Zones `$D55C` + 7n; 34 zones in 4 levels (doc 1, 7) |
