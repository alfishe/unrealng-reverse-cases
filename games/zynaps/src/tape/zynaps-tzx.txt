# The TZX of the Hewson release (orig/Zynaps.tzx.zip), block by block: tools/tzx.py writes it from this file and the
# files the build assembles; tools/build.sh compares the result with the original byte for byte.
#
#   version MAJOR.MINOR                         the TZX header
#   info ID TEXT                                one string of the $32 archive-info block (ID in hex)
#   header PAUSE program NAME LINE FILE         a $10 block: a ROM header for a BASIC program (length and
#                                               parameter 2 = FILE's length); PAUSE in ms after it
#   header PAUSE bytes NAME START PARAM2 FILE   a $10 block: a ROM header for CODE (length = FILE's length)
#   data PAUSE FILE                             a $10 block: flag $FF, FILE, the XOR checksum
#
# Every data block is standard speed; blocks 5-8 only look like ROM files: the Countdown II loader reads them.
version 1.10
info 00 Zynaps
info 01 Hewson
info 02 Dominic Robinson
info 03 1987
info 04 English
info 05 Arcade
info 06 7.99
info 07 Hewson Countdown II
info 08 Perfect TZX sampled from the original cassette by Church of the Latter-Day Speccy
info FF CRASH #42; "A first rate shoot-'em-up with the magical ingredients for high addictivity" 91% SMASH
header 1005 program zynaps 0 basic.bin
data 1009 basic.bin
header 1003 bytes loader 64512 20480 loader.bin
data 1010 loader.bin
header 1010 bytes picy 32768 16384 picy.bin
data 1003 picy.bin
header 996 bytes code 23976 25000 game.bin
data 0 game.bin
