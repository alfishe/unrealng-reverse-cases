# font

| File | Entry | Format |
| --- | --- | --- |
| `font.png` | `Font` `$7608-$77FF` (504 bytes) | 63 glyphs of 8x8 side by side, characters `$20-$5E` in order (PrintChar's base `$7508` = Font - `$100`); index 0 paper, 1 ink |
| `bigdigits.png` | `BigDigits` `$7C54-$7D7F` (300 bytes) | ten digits 0-9 of 16x15 side by side (BigDigit: the stage number, the countdown's big figures) |

Some codes draw the game's own shapes, not ASCII: `[ % \ + / ] ) ^ ( * & $` are frame pieces (FrameChars), `<>`
after K is km/h, `:` `;` `'` `!` `@` in the name grid are the font's own glyphs (texts/README.md).
