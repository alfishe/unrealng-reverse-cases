# The two BASIC programs load by the ROM. The second one's variables area holds the first decoder (Chain1 $621A,
# src/tape/basic2.asm) and the loader as tools/speedlock2.py tape enciphers it (loader-tape.bin, from the plain view

# leader of 2100 T tones broken by 1140 / 740 T pulse pairs and a 6-bit sync 111010; the loading screen after the
# same leader with 1163 / 711 T pairs; then each block after a mark of 21 bits at zero 875 T / one 1750 T
# (00000, eleven 1s, 00000), read at zero 565 T / one 1130 T with no leader. Where each block after the screen goes
# is the loader's table at $FF89 (BlockTable, 5 bytes a row: the address, the length less one, the $7FFD value);
# the last block follows on from the one before it.
