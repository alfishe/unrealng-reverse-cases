## Terms

Each term once, here; the documents link to it.

| Term | Meaning |
| --- | --- |
| GS | General Sound, the Z80 sound card with its own RAM (512 KB here), ProTracker module player and sample effects. The host writes commands to `$BB` (read: status, bit 0 command not taken, bit 7 data not read) and data to `$B3`. NeoGS is the newer compatible card |
| editions | Tron Z, 2002: the SCL and the TRD, loader `neart022`. Hood, 2017: the tape, loader `neart0222`, BASIC `NetherE GS` ([1.2](01-game-design.md#12-the-editions-and-how-each-starts)) |
| the two targets | one game source assembled plain (the disk's `neart001`) and with `-DHOOD_TAPE` (the tape's; 4 bytes differ) |
| the driver | the conversion's routine at `$C000` of its own RAM bank (`DriverBank`: 1 on the disk, 248 bytes `neart021`; 6 on the tape, 271 bytes) that turns the game's sound id into GS commands ([9.4](09-sound.md#94-the-drivers)) |
| sound id | the value the game passes in A to `GsSound` `$A583`; for the menus it is the beep's old half-period ([9.4](09-sound.md#94-the-drivers)) |
| effect, effect N | a sample on the GS card, the N-th loaded, as the driver numbers it; started with data n, `#2E`, data 47 (`#40`), data n, `#39`. 14 of them on the tape's card, 9 on the disk's ([9.2](09-sound.md#92-what-the-card-holds)) |
| the module | "_desert dream vol.2", the one ProTracker module, played from the end of the load for the whole game; tape only, the disk load loses it ([9.2](09-sound.md#92-what-the-card-holds)) |
| cold restart | GS command `#F4`: the card jumps to 0 and runs its RAM test, deaf to commands until it is done ([3.5](03-build-and-load.md#35-the-module-upload-and-the-cold-restart)) |
| ids 2 and 4 | the driver ids that choose among three effects by R; bit 7 of R never changes, so effects 2 and 8 never sound ([9.6](09-sound.md#96-r-and-effects-2-and-8)) |
| `SoundFx` | `$FD53`, the byte the game's world turn sets for the interrupt's sound: 1 a shot, `$FC` a miss, `$FA` a hit, `$C8` a kill |
| turn | one pass of `PlayLoop`: at least 10 frames, 5 minutes of game time ([4.3](04-game-loop.md#43-the-turn)) |
| day | 288 turns, at least 2 880 frames; production at midnight ([10.2](10-gameplay-logic.md#102-production-and-resources)) |
| the tear | a frame in which the beam overtakes the view copy, showing the new view above and the old below ([6.9](06-rendering.md#69-the-copy-and-the-beam)) |
| record | the 16 bytes of a robot (`$DA00` + 16 × slot, 48 slots: 0-23 ours, 24-47 the enemy's) or the 9 bytes of a shot (`$D7D3` + 9 × n, 5 records) ([7.2](07-objects.md#72-robots), [7.4](07-objects.md#74-shots)) |
| capture point | one of the 28 5-byte entries at `$FD70` (4 warbases, 24 factories); a robot on its door for 144 turns takes it ([7.6](07-objects.md#76-buildings-and-capture-points)) |
| order | `+$0B` of a robot record, 0-8 (STOP AND DEFEND .. CAPTURE ENEMY WARBASES) ([10.5](10-gameplay-logic.md#105-orders)) |
| the commander | `EnemyCommander` `$B7F4`, the enemy's whole intelligence: random builds and orders ([10.8](10-gameplay-logic.md#108-the-enemy-commander)) |
| friendly fire | a shot hits any live robot in its path, of either side ([7.4](07-objects.md#74-shots)) |
| NE, ANE | the cases [Nether Earth](../../nether-earth/README.md) (the 1987 game) and [Advanced Nether Earth](../../advanced-nether-earth/README.md); named here only for the side-by-side figures and the tools borrowed from them |
