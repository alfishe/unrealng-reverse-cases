## Terms

Each term once, here; the documents use these names and no others.

| Term | Meaning |
| --- | --- |
| BeamGlyphBytes | `$8000`: for each of the 16 directions, the four glyph numbers drawn round a vertex, in two sets (the second, at +`$40`, for the flashing beam); the glyphs themselves are BeamGlyphs `$D500` (doc 6) |
| BeamStep | `$8EDD`: one step of TraceBeam: move a half-cell, count the length `$8EBF`, act on the cell at a centre (doc 10) |
| CellsLeft | `$8380`: the cells still to burn; at 0 OpenReceiver opens the door (`$FF`), then the door's own explosion leaves `$FE` (doc 7, 10) |
| CopyPlayArea | `$8C10`: the copy of the marked characters and all 640 colours from the play buffers to the screen, timed against the raster (doc 6) |
| direction | 0-15 clockwise from east (4 south, 8 west, 12 north); a mirror of code m turns direction d into (m - 1 - d + 8) AND 15 (doc 10) |
| DrawMarks | `$E300`: one byte a character of the play area, laid out like the attributes; non-zero: DrawMarkedChars redraws it and CopyPlayArea copies it (doc 6) |
| explosion slots | `$81B8`: the records of the cells being burnt or blown up, stepped one code a pass; emptying a slot counts a cell off CellsLeft (doc 7) |
| gremlin record | a gremlin's position, delay and target mirror; UpdateGremlins `$AB9F` moves them and turns the mirror they sit on (doc 7, 10) |
| half-cell lattice | the beam's coordinates: x 0-32 and y 0-20 count half-cells; a vertex with both even is a cell's centre, where the cell acts (doc 10) |
| hall of fame | six records of name and score (MEGA 090000 to AWFUL 015000); a score that ranks asks for a name: up to five letters, SPACE, DELETE (0), ENTER (doc 8) |
| MessageNumber | `$A104`: the COMPUTER line's message; a new message replaces the shown one only by priority (doc 8) |
| OVERLOAD | the beam back into the laser, or a trace of 40 steps or 40 wall bounces: the overload bar rises a step a pass; full, a life is lost (doc 10) |
| pass | one run of MainLoop `$854A` and PassEnd `$85AE`; it never waits for the frame (4.85 frames a pass in the RZX run) (doc 4) |
| PlayNoise | `$A87A`: the burning cell's noise, from a self-modifying opcode (always `AND D`) (doc 9) |
| PlaySweep | `$A85E`: a sound record of steps, a tone whose period moves each step (GremlinSound, CONTACT!, BurnSound) (doc 9) |
| practice | option 6: levels P1-P3 from slots 60-62, energy rate 255, a full overload bar takes no life, no score kept (doc 5) |
| ScoreDigits | `$9B3F`: the score as ASCII digits, spaces for leading zeros; a fixed 0 is printed after them (doc 8) |
| SoundFlags | `$A8A6`: the bits the interrupt plays: 1 mine, 2 laser, 3 burn, 4 charge; bit 0 is never set (doc 9) |
| TwoTone | `$A843`: the warble: two square waves XORed, a pulse whose width slides; pitch 3.5 MHz / ((256 - L) x 56) Hz (doc 9) |
