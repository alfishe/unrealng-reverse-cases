## Terms

Each term once, here; the documents use these names and no others.

| Term | Meaning |
| --- | --- |
| access code | the 16 digits REX 1 prints at its end (CodePanel `$A7CE`) and REX 2 asks for (EnterCode `$DB27`): 13 places of state, each written 9 - digit, then a 3-digit checksum; it joins part 1 and part 2 (docs 1, 8, 10) |
| attribute shadow | `$E4FF`, the screen's attributes as they should be; CopyAttrs copies its play rows to `$5860` (doc 6) |
| back buffer | the play area's 168 lines of 32 bytes at `$EB00-$FFFF` (BackBuffer); ClearBuffer empties it by `PUSH`, BufferToScreen copies it to the screen once a pass (doc 6) |
| big squidgy thing | REX 2's boss, a mass of type 4 cells; one bullet starts its 100-pass explosion (BossHit, BossExplodes; doc 10) |
| bonus roulette | the bonus pod's panel of five prizes (SPEED UP, SHIELD LOSS, 1000 BONUS, ENERGY LOSS, 100 RAPID SHOTS) shown in turn, slower each time; fire takes the prize shown, without fire it stops by itself (BonusRoulette; docs 8, 10) |
| combo row | HUD row 2, "100 ... 900", lit by KillFlashPtr `$A039` one cell a hit and faded by KillFlashFade (doc 8) |
| descriptor | a sound effect's 9-byte record: [channel 1-3][noise flag][steps][volume x 16][period word], then 3-byte steps (doc 9) |
| development link | the leftover code at the start of each code block that talked to the authors' machine over ports `$7F`, `$3F`, `$5F`; never run (doc 2) |
| fixed frame | a sprite drawn from SpritePicture with SpriteMirror bit 7 set: the frame list is ignored and the sprite moves in 8-pixel steps (doc 6) |
| heat | DEMO's unused HUD mechanic: HeatColour stays 7, HeatLeftover is never called (doc 10) |
| origin | the base a buffer writer adds `32 x Y + X / 8` to (ShotBufferOrigin `$E7FF`, SparkleBufferOrigin `$E89F`, SpriteBufferOrigin `$E8FF`, ObjectBufferOrigin `$E9FF`, BufferPlayOrigin `$EAFF`); not a buffer (doc 6) |
| pass | one run of the main loop from MainPass `$9586` (REX 2 `$9588`), about 4.4 frames in part 1; no interrupt paces it, and every speed and timer counts passes (doc 4) |
| pod | an object Rex takes: `$FE` power (the big one gives two gains), `$FD` a smart bomb, `$FC` the bonus roulette (doc 10) |
| power count | PowerCount `$A018`, the progress inside a power level: +38 a pod, a level up at 120; -1 a special shot, 50 after a level down (doc 10) |
| power level | PowerLevel `$A014`, 1-5 inside a rank; a sixth level moves up a rank (GainRank), at the top rank it stays 6; the power bar's end colour is the level + 2 (docs 8, 10) |
| pre-shifted copy | one of the 2, 4 or 8 stored versions of a sprite, picked by X & 7 through a frame list (ShiftFrames `$AE5D` and the like; doc 6) |
| rank | WeaponRank `$A06E`, 0-4: how far up the five weapons the power reaches; BestWeapon picks the best weapon held up to it (doc 10) |
| reader | one of the five 12-byte routines `$A46A-$A4E6` whose port and `BIT` opcode the menu or DEFINE writes (doc 5) |
| recharger | a pair of type 8 cells: +1 shield a pass while the shield is off, up to 99 (doc 10) |
| restart marker | a pair of type 7 cells: Rex's restart point is saved there when RexX AND 7 = 2 (SaveRestart; doc 10) |
| scenery cell list | SceneryCellList `$D962`, every visible scenery cell of the room as (buffer address, picture address); DrawRoom fills it, DrawAnimCells redraws it every pass over the sprites (doc 6) |
| smart bomb | SPACE: kills one object record a pass for 16 passes and stops every enemy bullet; 3 at the start, one free at each death (doc 10) |
| station | a pair of cells `$0A-$0D` that gives the double fire, the laser, the multiple or the spray, with its weapon panel (REX 1 rooms 1, 6, 23, 11; none in REX 2; doc 10) |
| sweep | the HUD light that runs along row 1, a per-room time limit: width 12 after a room change or a death, one less every 5 round trips, Rex dies when it would drop to 0 (HudSweep; docs 8, 10) |
| tear | the one frame a pass where BufferToScreen and the beam cross (line 135 in `p1-cursor` frame 1012; doc 6) |
| text record | [attribute][column][pixel line] characters, 0 (PrintText `$A307`; doc 8) |
| weapon panel | [flag][count][records], the text a station shows once, while its flag is 0 (WeaponPanel `$D871`; doc 8) |
