# Side A of the Firebird release (orig/Elite.tzx.zip, "Elite - 48k - Side A.tzx"), block by block: tools/mktape.py
# writes it from this list and the files the build makes; tools/build.sh compares the result byte for byte.
# docs/03-build-and-load.md 3.1-3.7.
#
#   version MAJOR MINOR                          the TZX header
#   text TEXT                                    a $30 text block
#   header PAUSE program NAME LINE VARS FILE     a $10 ROM header for a program (length = FILE's length)
#   data PAUSE FILE [LO HI]                      a $10 block: flag $FF, FILE (or its bytes LO-HI, hex addresses of
#                                                game.bin, which starts at $5B00), the XOR checksum
#   group NAME / group-end                       $21 / $22
#   turbo PILOT SYNC1 SYNC2 ZERO ONE PULSES LAST PAUSE FILE...
#                                                a $11 block: flag $FF, the files one after another, the checksum,
#                                                every byte bit-reversed (the Softlock loader reads bit 0 first)
#   chunk ZERO ONE LAST ADDRESS SOURCE           two $14 blocks with no pause: the 4-byte header (length, ADDRESS)
#                                                and the data with its check byte (the XOR of the chunk is 0), all
#                                                bit-reversed; SOURCE is a file, "zeros:N", "rom:LO:N", "tape:LO:HI"
#                                                (the plain memory tools/mktape.py builds, encrypted where the
#                                                decryptor works) or "filler:N:OFFSET:FILE" (N zeros, FILE at OFFSET)
#   pure ZERO ONE LAST PAUSE HEX                 a $14 block of these bytes, bit-reversed
