## Recordings

| Name | What |
| --- | --- |
| `r1`, `r2` | stage 3's recordings from power-on on Pentagon 128 + TR-DOS (`work/stage3/r1`, `r2`); frame = input-script frame + 1602 |
| `deep` | the long game: 3415 turns, 11.9 game days ([10.13](10-gameplay-logic.md)) |
| `tour` | a scripted session from the game-menu snapshot (`tools/fig_tour.py tour`, `work/docP/tour`); frames count from the snapshot |
| `lose`, `win` | two runs from the `tour`'s first play frame with `PlayerBuildings` `$FD3A` or `EnemyBuildings` `$FD42` poked to 0: they reach Dead End and Final Cut |
| `ane_sim` | `tools/ane_sim.py`, the static boot run (SkoolKit simulator, 128K paging, a WD1793 model); its frames are its own, 71 680 T, frame 0 = the BASIC's `USR` |

## Terms

Each term once, here; the documents link to it.

| Term | Meaning |
| --- | --- |
| frame | one 50 Hz screen frame of the Pentagon: 71 680 T, one interrupt. The recordings count frames from their own start |
| T, T-state | one Z80 clock cycle at 3.5 MHz |
| game turn | one pass of `PlayLoop`: the world turn, the clock + 5 minutes, captures; at least 10 frames (`TurnPace`) |
| world turn | `WorldTurn`: the enemy commander, then every live robot record, then every live shot record |
| capture point | one of the 28 five-byte records at `$FD70`: 4 warbases, then 24 factories; door cell, owner, count |
| door | the cell a robot must stand on for 144 turns to capture a building |
| warbase | a base where robots are built (on its pad) and that yields 5 general resource a day |
| factory | a base that yields 2 of one resource a day |
| destroyed base | a capture point with owner bit 7 after a nuclear blast; it can be captured again, as a warbase ([10.11](10-gameplay-logic.md)) |
| step delay | robot `+$0F`: the turns until its next step, from `StepDelays` by locomotion and ground |
| order | robot `+$0B`, 0-8: stop, advance, retreat, hunt robots, destroy factories / warbases, capture neutral / enemy factories / warbases |
| general resource | resource 0: pays what a part's own resource cannot; 5 a day per warbase |
| space dollar (космодоллар) | the unit of the resources in the help |
| Isignians (исигнианцы) | the help's name for the aliens; the panel says ИНОП |
| Dead End / Final Cut | the lost and the won endings: bank 3 `$D2EF`, and bank 6 copied to `$6060` |
| GameBank | `$67D9`, the last `$7FFD` value the game set; the music handlers page it back |
| PrintInline | the game's text printer `$D42D`; the string follows the CALL, control codes 0-4 |
| help encoding | the help's Russian stored as Latin letters that its Cyrillic font draws (a=а ... q=я, w=в, `[`=ш); `tools/help_text.py`, `tools/bootmenu_res.py` |
| UltraXOR | Paracels' v1.2 protection envelope: 78 self-decrypting loops at `$7705-$813A` around the sector reader |
| the reader | UltraXOR's sector reader at `$5D3F`, reading by logical sector through TR-DOS ROM gadgets |
| HRUM 3.5 | Dmitry Pyankov's packer; a block = 31-byte set-up + 119-byte depacker + stream, unpacking in place |
| Hrust 1 | the packer of the boot menu's pictures and of the 2017 Final Cut disk (`HR` header) |
| block N | the rows of [3's packed-blocks table](03-build-and-load.md): 1 the intro ... 13 Final Cut, 14 the plain title picture |
| sector numbers | counted from `A_NETHER.B`'s first sector across the files (sector k = logical 16 + k) |
| the game starter | the code at `$9C40-$B78F` unpacked from bank 7's image after boot menu key 1 |
| the disk module | bank 4's save / load program, copied to `$4000` (`$4000` load, `$4033` save) |
