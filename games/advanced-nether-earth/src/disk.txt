# The SCL's four files and what lies in their sectors (tools/mkdisk.py; docs/03-build-and-load.md 2).
#
#   file NAME TYPE START LENGTH SECTORS     a catalogue entry (TR-DOS: 8-character name, type letter, the two
#                                           words, the length in sectors); its sectors follow from here on
#   at SECTOR+OFFSET PATH [FROM [COUNT]]    the bytes of PATH (FROM, COUNT: a part of it, decimal or $hex) at the
#                                           file's sector SECTOR, byte OFFSET; the parts of a file are in order and
#                                           leave no hole: every byte comes from a listed file
#   zero SECTOR+OFFSET COUNT                COUNT zero bytes
#   text SECTOR+OFFSET PATH                 a text file: UTF-8, lines ended CR LF, written in CP866
#
# Sector numbers are the file's own (0 = its first). The loader reads by the disk's logical sectors: file sector
# k of A_NETHER.B is logical sector 16 + k; a_nether.E follows at file sector 255, nether.N at 437, NETHER+.W
# at 476 (the numbers below count from A_NETHER.B's first sector, across the files, as the loader's reads do).
