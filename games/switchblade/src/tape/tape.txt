# in order. Format:
#   tzx MAJOR.MINOR                         the file header ("ZXTape!", $1A, the version)
#   text TEXT                               a text description block ($30)
#   header PAUSE TYPE NAME LENGTH P1 P2     a standard ($10) ROM header block: flag $00, type 0 (Program), the name
#                                           padded to 10 ("_" for a space), the data length ("@FILE": the file's),
#                                           P1 (the auto-run LINE), P2 (the program length; "=" the data length)
#   data PAUSE ITEM [ITEM ...]              a standard ($10) data block: flag $FF, the items' bytes in order, the XOR
#                                           checksum; an ITEM is a file of build/ or NAME@ORG:LO-HI, the bytes LO..HI-1
#                                           of NAME, whose first byte is at ORG (hex)
