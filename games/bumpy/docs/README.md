## Terms

Each term once, here; the documents use these names and no others.

| Term | Meaning |
| --- | --- |
| AY register image | the 16-byte block after each sound effect's `LD HL`: AY registers R0-R13 and two zeros, the block WriteAyRegisters `$F190` would write; unread on the 48K (doc 9; `src/res/sound/ay-images.csv`) |
| burst | state 6, BallBurst `$B14A`: the death picture sequence before LoseLife |
| cell | one of the 36 places of the board, 6 rows of 6, BallCell `$AA44` 0-35 row by row from the top; a platform type, a wall and an object each |
| CPC address | a screen address of the Amstrad CPC original, `$C000` + line part x `$800` + row x 80 + byte, converted to Spectrum lines by SpectrumLines `$B52D` |
| drifting replay | a recording that replays the RZX's inputs from a level's start but leaves the RZX's path (12 of stage 1's `rzx/lNN`); the deaths in the recordings come from them, from `fire`, from `rightspike` or from S |
| fall out | state 7, BallFallOut `$B20A`: no platform under a landing on the bottom row |
| key code | row x 8 + bit, as TestKey and KeySlots `$F084` use it; row 8 is the Kempston port |
| landing | the end of a move, where LandingCheck `$B09E` and ChooseNextState `$B7E4` pick the next state; the moment the keys choose the next move (the spring is armed earlier, at step 9 or a fall's step 4; on a stopper the keys are read every pass) |
| move | one of the five offset tables run step by step: bounce, left, right, up, down |
| pass | one turn of MainLoop `$ACC8`: one step of the ball, then the frame wait; most take one frame, some two or more |
| platform type | the cell's low nibble in the level record: 0 none, 1 plain, 2-4 crumbling, 5 stopper, 6-7 conveyors, 8-9 burning, 10 bricks, 11 exit, 12 spikes |
| PrintText code | a control byte in a text: `$16` AT, `$01`/`$02` height, `$10`-`$15` colours (`$14` the whole attribute), `$00` end |
| quiet flag | ObjectFlag `$ABA7`: 4 after the bottle or a water drop spent on a fire, so the next bounce, jump or pick-up is silent |
| spring | SpringArmed `$AA13`: up or fire held at step 9 of a bounce or a side move, or at step 4 of a fall, with the ball's platform 1-5; the landing then starts an up move |
| step | one dispatch of the ball's state; BallStep `$A9FF` counts them (16 for a bounce or a side move, 8 up or down) |
